# Parallel Identification Guide

Permanent reference for visually identifying card parallels. Built from
Beckett, ChecklistInsider, WNBAcards, and CardZN data. Update as new sets
release.

---

## How to read this guide

Every parallel has THREE properties:
1. **Surface texture** — the physical pattern (dots, cracked ice, swirl, etc.)
2. **Color** — the primary hue
3. **Print run** — numbered (e.g., /199) or unnumbered

To identify a card from a photo, work from largest visual cue to smallest:
- **Border color** (red, blue, pink, purple, orange, green, teal, yellow) → narrows by 80%
- **Surface pattern** (clean, ice cracks, snake scales, sparkles, dots) → narrows further
- **Numbered serial** (visible /XX on card) → confirms exact parallel

If the card has no border color and looks like clean shiny chrome → it's
either Base, Silver, or one of the patterned unnumbered SSPs.

Largely the same as 2025 with these differences:
- HAS Hyper Prizms (still in 2024, gone in 2025)
- DOES have Pulsar Prizms unnumbered tier (/499) — 2025 doesn't
- HAS Pink Velocity /79 and Black Velocity /39 (hobby exclusives)
- Has Premium Box Set Prizms /99
- Snake Skin Prizms (note spelling on checklist)
- WNBA Logo Prizms exclusive to Dick's Sporting Goods blaster boxes (6 per box)

### 2023 Prizm WNBA

- Has Hyper, Blue Wave, Red Wave (UNIQUE to 2023, distinct from Ice/Cracked Ice)
- Has Cracked Ice as retail exclusive (UNIQUE name in 2023; renamed to Ice in 2024+)
- No White Sparkle, no White Seismic
- Premium Scope /99 is unique to 2023
- Mosaic /3 exists

- 200-card base set (UNIQUE — biggest)
- Has Hyper, Cracked Ice, Red Wave, Green Cracked Ice (Fanatics exclusive)
- Has White Sparkle (limited 3-card packs)
- Has Mosaic /3
- W25 subset

### 2021 Prizm WNBA

- 100-card base set
- Has Hyper, Cracked Ice, Green Cracked Ice (Fanatics)
- Has White Sparkle (limited packs)
- Has Mosaic /3
- Black 1/1 (no Gold Vinyl yet)

### 2020 Prizm WNBA (the inaugural)

- 100-card base set

## Visual identification heuristics — quick decision tree

When evaluating a photo from eBay/COMC, ask in order:

**1. Is there a visible serial number printed on the card?**
- YES → it's a numbered parallel. Read the number, match to print-run table.
- NO → continue to step 2.

**2. Is there a clear color tint to the border or background?**
- Red → Red Prizms (or Red [pattern])
- Pink → Pink Prizms / Pink Shimmer / Pink Lava
- Blue solid → Blue Prizms (numbered)
- Blue with streaks → Blue Velocity (unnumbered)
- Green border → Green Prizms (retail unnumbered) or Green Pulsar (numbered)
- Orange → Orange Prizms / Orange Velocity / Orange Lava
- Yellow → Yellow Lava (Donruss only)
- Purple → Purple Prizms
- Teal → Teal Prizms (numbered)
- Gold → Gold Prizms (top tier)
- No tint → continue to step 3.

**3. What's the surface texture?**
- Clean smooth chrome → Base or Silver Prizms (Silver shows full rainbow refraction at angle)
- Cracked-glass pattern → Ice Prizms (or Cracked Ice in 2022-2023)
- Scaly diamond pattern → Snakeskin Prizms
- Diagonal multi-color stripes → Hyper Prizms (2020-2024 only, gone in 2025)
- Wavy brushstrokes → Swirl Prizms (2025+)
- Tiny dots/jewels → Pandora Prizms (2025+)
- Tiny white sparkles → White Sparkle Prizms
- Concentric rings/sunburst from center → Pulsar variant
- Heavy bright rainbow → Mojo Prizms (numbered /25)
- Solid black → Black Finite (1/1)

**4. Cross-reference against a reference image** in the repo at
   `parallels/<product>/<variant>/candidate-*.jpg`

## Common confusion pairs (USE EXTRA CARE)

| A | B | How to tell apart |
|---|---|---|
| Silver vs Hyper | both have rainbow refraction | Silver = whole-card vertical rainbow; Hyper = diagonal multi-color stripes |
| Ice vs Snakeskin | both look "cracked" | Ice = angular sharp shards; Snakeskin = round/oval scales |
| Ice vs Cracked Ice | naming changed | Same pattern; "Cracked Ice" was 2022-2023 name, became "Ice" in 2024+ |
| Hyper vs Swirl | both colorful patterns | Hyper = straight diagonal stripes; Swirl = wavy curves |
| White Sparkle vs White Seismic | both have white | White Sparkle = small white dots/stars; White Seismic = white cracked-ice on white field |
| Blue vs Blue Velocity | both blue | Blue (numbered) = solid border tint; Blue Velocity (unnumbered) = blue with linear streaks |
| Lava (Donruss) vs Lava (Revolution) | same name diff product | Different visual treatments. Always note which product you're in. |
| Pulsar vs Cosmic | both have radiating effect | Pulsar = concentric rings from a point; Cosmic = scattered stars across whole field |
| Refractor (BU Best) vs Refractor (BU Chrome) | same name diff product | Different photos entirely. Don't cross-reference photos between products. |

## When in doubt

1. Find the player's full **Trading Card Database (TCDB)** page via search
2. Look at the variant list for that exact card number
3. Compare photo against the TCDB thumbnail
4. If still unsure, mark as "review needed" in the tracker note and verify
   when the physical card arrives
